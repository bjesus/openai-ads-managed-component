# OpenAI Ads Measurement Managed Component

This repository is an experimental baseline generated by the Zaraz Managed
Components Lab from captured OpenAI Measurement Pixel behavior. It is not an
official OpenAI project.

## Documentation

Managed Components docs are published at **https://managedcomponents.dev** .

Find out more about Managed Components [here](https://blog.cloudflare.com/zaraz-open-source-managed-components-and-webcm/) for inspiration and motivation details.

## 🚀 Quickstart local dev environment

1. Make sure you're running node version >=18.
2. Install dependencies with `npm i`
3. Run unit test watcher with `npm run test:dev`

## ⚙️ Tool Settings

> Settings are used to configure the tool in a Component Manager config file

### Pixel ID `string` _required_

The OpenAI Ads Pixel ID used to associate measurement events.

## 🧱 Fields Description

> Fields are properties that can/must be sent with certain events

The implementation and supported fields are generated and reviewed from
captured protocol evidence before publication.
